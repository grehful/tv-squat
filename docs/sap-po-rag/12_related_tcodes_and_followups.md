# 발주 관련 T-code

## 구매오더

| T-code | 기능 |
|---|---|
| `ME21N` | PO 생성 |
| `ME22N` | PO 변경 |
| `ME23N` | PO 조회 |
| `ME29N` | PO 개별 승인 |
| `ME28` | PO 일괄 승인 |
| `ME9F` | PO 출력(메시지) 처리 |

## 구매오더 목록 리포트

| T-code | 검색 기준 | 용도 |
|---|---|---|
| `ME2L` | 공급업체 | 벤더별 미결 PO, 중복 발주 확인 |
| `ME2M` | 자재 | 자재별 발주 현황 |
| `ME2N` | PO 번호 | 번호 범위 조회 |
| `ME2K` | 계정지정 | 비용센터·WBS별 발주 |
| `ME80FN` | 통합 | 구매 문서 종합 분석 |

선택 화면의 `Selection Parameters`에 `WE101`을 넣으면 아직 입고되지 않은 PO만 볼 수 있습니다.

## 구매요청·마스터

| T-code | 기능 |
|---|---|
| `ME51N` / `ME52N` / `ME53N` | PR 생성 / 변경 / 조회 |
| `ME5A` | PR 목록 |
| `ME11` / `ME12` / `ME13` | 정보레코드 생성 / 변경 / 조회 |
| `ME01` / `ME03` | 소스 리스트 유지 / 조회 |
| `ME31K` / `ME33K` | 계약 생성 / 조회 |
| `MM03` | 자재 조회 |
| `BP` (S/4) / `XK03`, `MK03` (ECC) | 공급업체 조회 |
| `MMBE` | 재고 현황 |
| `MD04` | 재고/소요 리스트 |

## 후속 처리(에이전트 범위 밖, 안내만)

| 단계 | T-code | 비고 |
|---|---|---|
| 입고 | `MIGO` (이동유형 `101`) | 승인된 PO만 가능 |
| 입고 취소 | `MIGO` (이동유형 `102`) | |
| 송장검증 | `MIRO` | 3-way 매칭(PO·입고·송장) |
| PO 이력 | `ME23N` 품목 상세 → `Purchase Order History` 탭 | 입고·송장 내역 |
