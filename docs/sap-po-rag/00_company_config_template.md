# 회사별 SAP NERP 발주 설정값

> **작성 안내:** `<...>`를 실제 값으로 바꾸세요. 에이전트는 PO를 만들 때 이 문서의 값을 기본값으로 씁니다.
> 값이 비어 있으면 에이전트는 추측하지 말고 사용자에게 물어봐야 합니다.

## 시스템 정보

| 항목 | 값 | 비고 |
|---|---|---|
| SAP 제품 | `<ECC 6.0 / S/4HANA 20xx>` | |
| 연동 방식 | `<OData / RFC(BAPI) / 둘 다>` | 06, 07 문서 중 어느 쪽을 쓰는지 |
| 클라이언트(Client) | `<예: 100>` | |
| 운영 전 테스트 시스템 | `<QAS 시스템 ID>` | 에이전트 검증은 여기서 먼저 |

## 조직 단위

| 항목 | SAP 필드 | 값 | 설명 |
|---|---|---|---|
| 회사코드 | `CompanyCode` / `COMP_CODE` | `<예: 1000>` | |
| 구매조직 | `PurchasingOrganization` / `PURCH_ORG` | `<예: 1000>` | |
| 기본 구매그룹 | `PurchasingGroup` / `PUR_GROUP` | `<예: 001>` | 담당 구매자 그룹 |
| 기본 통화 | `DocumentCurrency` / `CURRENCY` | `<KRW>` | |
