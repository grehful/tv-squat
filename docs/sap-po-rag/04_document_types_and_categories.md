# 문서유형, 품목범주, 계정지정범주

## 문서유형(Document Type)

| 코드 | 이름 | 언제 쓰나 |
|---|---|---|
| `NB` | 표준 구매오더 | 일반적인 외부 구매. **기본값** |
| `FO` | 프레임워크 오더 | 기간 단위로 한도 금액을 잡아 두는 구매(소모품, 서비스) |
| `UB` | 재고이전오더(STO) | 회사 내부 플랜트 간 재고 이동 |
| `Z*` | 회사 고유 유형 | `00_company_config_template.md` 참고 |

## 품목범주(Item Category)

| GUI 코드 | 내부 값 | 이름 | 설명 |
|---|---|---|---|
| (공란) | `0` | 표준 | 일반 구매 |
| `K` | `2` | 위탁(Consignment) | 벤더 소유 재고를 창고에 두고 쓸 때 정산 |
| `L` | `3` | 외주가공(Subcontracting) | 원자재를 벤더에 제공하고 가공품을 받음 |
| `D` | `9` | 서비스 | 서비스 구매(서비스 명세 필요) |
| `U` | `7` | 재고이전 | 문서유형 `UB`와 함께 사용 |
| `S` | `5` | 제3자 거래 | 벤더가 고객에게 직송 |

> OData/BAPI에는 GUI 코드가 아니라 **내부 값**이 들어가는 경우가 많습니다. 예: 외주가공은 `L`이 아니라 `3`. 시스템에서 한 건 만들어 보고 값을 확인하세요.

## 계정지정범주(Account Assignment Category)

| 코드 | 이름 | 필요한 추가 정보 | 예시 |
|---|---|---|---|
| (공란) | 재고 구매 | 저장위치 | 원자재, 부품 |
| `K` | 비용센터 | 비용센터, G/L 계정 | 사무용품, 소모품 |
| `F` | 내부오더 | 내부오더 번호, G/L 계정 | 행사비, 수선비 |
| `P` | 프로젝트 | WBS 요소, G/L 계정 | 프로젝트 자재 |
| `A` | 자산 | 자산번호 | 노트북, 설비 |

## 선택 규칙(에이전트용)

1. 자재번호가 있고 창고에 재고로 쌓는 물건 → 계정지정범주 **공란**, 저장위치 입력
2. 부서에서 바로 쓰는 소모품·서비스 → **`K`** + 요청 부서의 비용센터
3. 특정 프로젝트 비용 → **`P`** + WBS
4. 자산으로 등록할 장비 → **`A`** + 자산번호(자산이 없으면 회계팀에 먼저 생성 요청)
5. 판단이 안 서면 추측하지 말고 사용자에게 물어봅니다.
