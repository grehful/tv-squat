# 스마트스토어 재입고 알림

상품 페이지를 1분 정도마다 확인하다가 **품절 → 판매중**으로 바뀌면 휴대폰으로 알림을 보냅니다.
자동 구매는 하지 않습니다. 알림을 누르면 상품 페이지가 열리니, 바로 들어가서 직접 결제하세요.

## 1. 휴대폰 준비 (ntfy 앱, 무료, 가입 필요 없음)
1. 앱스토어나 플레이스토어에서 **ntfy**를 설치합니다.
2. `+` 버튼을 누르고 **토픽 이름**을 입력해 구독합니다. 예: `pokemon-moncolle-8371`
   - 이름을 아는 사람은 누구나 알림을 보낼 수 있으니 **남이 못 맞힐 이름**으로 정하세요.
3. 아이폰은 알림 설정에서 ntfy 알림을 허용해 주세요.

## 2. 컴퓨터 준비
1. [Python](https://www.python.org/downloads/)을 설치합니다. 윈도우에서는 설치할 때 **"Add Python to PATH"를 체크**하세요.
2. 이 폴더에서 명령 프롬프트(터미널)를 열고 아래를 실행합니다.
   ```
   pip install -r requirements.txt
   ```

## 3. 실행
알림이 잘 오는지 먼저 테스트합니다.
```
python restock_alert.py --topic pokemon-moncolle-8371 --test
```
휴대폰에 알림이 오면 감시를 시작합니다.
```
python restock_alert.py --topic pokemon-moncolle-8371
```
- 다른 상품을 감시하려면 `--url 상품주소`를 붙이세요.
- 확인 간격을 바꾸려면 `--interval 초`를 붙이세요. 기본값은 60초이고, 최소 20초입니다.
  너무 자주 확인하면 네이버가 접속을 막을 수 있습니다.
- 끄려면 `Ctrl+C`를 누르세요.

**프로그램이 돌아가는 동안 컴퓨터가 켜져 있어야 합니다.** 절전 모드로 들어가지 않게 설정해 두세요.

## (선택) 텔레그램으로도 받기
```
python restock_alert.py --topic 토픽이름 --telegram-token 봇토큰 --telegram-chat-id 채팅ID
```

## 잘 안 될 때
- 로그에 `페이지에서 판매 상태를 찾지 못함`이 계속 뜨면 네이버 페이지 구조가 바뀐 것입니다. 코드를 수정해야 합니다.
- `접속을 제한함 (HTTP 429/403)`이 자주 뜨면 `--interval`을 120 이상으로 늘려 주세요.
