# TV 스쿼트 📺🏋️

아이들이 TV를 보는 동안 **카메라로 스쿼트를 세고**, 정해진 시간마다 할당량을 못 채우면 **삼성 TV를 꺼버리는** 프로그램입니다.

- 기본 규칙: **30초에 1개**, **5분마다 10개** 검사 → 못 채우면 TV 꺼짐
- TV가 꺼진 뒤 스쿼트 10개를 하면 TV가 다시 켜짐 (끌 수 있음)
- 1개당 시간, 검사 주기, 인원 수, 인식 민감도는 **화면의 [설정] 버튼**이나 명령줄에서 바꿀 수 있음
- TV가 꺼져 있는 동안은 타이머가 멈춤 (TV 안 볼 때는 운동 안 해도 됨)
- TV가 꺼진 상태에서 아이가 리모컨으로 다시 켜면 자동으로 다시 끔
- 여러 명(최대 4명)이 함께 해도 각각 인식해서 합산
- 숫자를 음성으로 세어주고, 1분 남았을 때 경고 음성

## 준비물

- 카메라가 있는 노트북/PC (TV 옆에 두고 아이들 전신이 보이게)
- 같은 공유기(와이파이)에 연결된 **삼성 스마트 TV (2016년 이후 Tizen 모델)**
- Python 3.9 이상, Chrome/Edge 브라우저

## 📱 안드로이드 앱 (PC 없이 휴대폰만으로)

휴대폰 하나로 카메라 인식 + 타이머 + TV 제어를 모두 합니다. PC 서버가 필요 없어요.

1. APK 설치: `android/build/tv-squat.apk` 를 휴대폰으로 옮겨 설치 (설치 시 "출처를 알 수 없는 앱" 허용 필요)
   - GitHub의 **Actions → Android APK** 에서 빌드된 APK(`tv-squat-apk`)를 받을 수도 있어요
2. 앱을 열고 카메라 권한 허용
3. **[설정] → 삼성 TV → [TV 찾기]** → 목록에서 TV 선택 (IP·MAC 자동 입력)
4. TV가 켜진 상태에서 **[TV 연결(최초 1번)]** → TV 화면의 허용 팝업에서 **허용**
5. **[끄기 테스트] / [켜기 테스트]** 로 확인한 뒤 [저장]
6. 휴대폰을 세워서 아이들 전신이 보이게 두면 끝. 앱이 켜져 있는 동안 화면이 꺼지지 않아요

- 휴대폰과 TV는 **같은 와이파이**에 있어야 합니다.
- 카메라는 설정에서 전면/후면을 고를 수 있어요 (후면이 화질이 더 좋음).
- 앱을 끄거나 다른 앱으로 넘어가면 개수가 안 올라가서 결국 TV가 꺼집니다.
- PC 브라우저에서 `http://localhost:8765/?local` 로 열면 앱과 같은 화면을 가상 TV로 시험해 볼 수 있어요.

APK 직접 빌드 (Ubuntu, Android Studio 불필요):

```bash
sudo apt-get install -y aapt apksigner zipalign dalvik-exchange android-sdk-platform-23
./android/build.sh        # → android/build/tv-squat.apk
```

`android/debug.keystore` 는 시험용 서명 키입니다 (같은 키로 빌드해야 앱을 지우지 않고 업데이트 설치 가능).

## 💻 PC 버전

## 1. 설치

```bash
git clone <이 저장소>
cd tv-squat
pip install -r requirements.txt
```

## 2. TV 설정

1. TV의 IP 주소 확인: `설정 > 일반 > 네트워크 > 네트워크 상태 > IP 설정`
   (공유기에서 TV IP를 고정해 두면 편해요)
2. TV를 다시 켤 수 있게 하려면: `설정 > 일반 > 네트워크 > 전문가 설정 > 모바일로 TV 켜기` **켜기**
3. 2024년 이후 모델은 `설정 > 일반 > 외부 기기 관리자 > 기기 연결 관리자 > 접근 알림` 이 켜져 있는지 확인

(메뉴 이름은 모델/연식에 따라 조금 다를 수 있어요.)

TV가 켜진 상태에서 연결 승인(최초 1번):

```bash
python -m tvsquat pair --tv-ip 192.168.0.20
```

TV 화면에 뜨는 "TV Squat" 연결 요청에서 **허용**을 누르면 `tv-token.txt`가 생깁니다.

TV MAC 주소 확인 & 전원 테스트:

```bash
python -m tvsquat status --tv-ip 192.168.0.20            # 켜짐/꺼짐, 모델명, MAC 표시
python -m tvsquat off --tv-ip 192.168.0.20               # TV 끄기 테스트
python -m tvsquat on  --tv-ip 192.168.0.20 --tv-mac AA:BB:CC:DD:EE:FF   # TV 켜기 테스트
```

> 유선(LAN)으로 연결된 TV라면 무선 MAC 대신 유선 MAC을 써야 할 수 있어요 (TV 설정의 네트워크 상태에서 확인).

## 3. 실행

```bash
python -m tvsquat --tv-ip 192.168.0.20 --tv-mac AA:BB:CC:DD:EE:FF
```

브라우저에서 **http://localhost:8765** 를 열고 카메라를 허용하세요. 아이들 **발끝까지 전신**이 보이도록 카메라를 두면 됩니다.

TV 없이 먼저 시험해 보려면:

```bash
python -m tvsquat --dry-run
```

### 규칙 바꾸기

화면의 **[설정]** 버튼으로 언제든 바꿀 수 있고(`settings.json`에 저장되어 재시작해도 유지), 명령줄에서도 됩니다:

```bash
# 20초에 1개, 10분마다 검사, 아이 2명 (→ 10분마다 합계 60개)
python -m tvsquat --tv-ip 192.168.0.20 --tv-mac AA:BB:CC:DD:EE:FF \
    --seconds-per-squat 20 --window-minutes 10 --players 2
```

| 설정 | 기본값 | 설명 |
|---|---|---|
| 스쿼트 1개당 시간 | 30초 | 할당량 = 검사 주기 ÷ 이 값 × 인원 |
| 검사 주기 | 5분 | 이 시간마다 할당량을 검사 |
| 함께 하는 아이 수 | 1 | 인원만큼 할당량이 늘어남 (합산) |
| TV 다시 켜기 | 켬 | 꺼진 뒤 할당량만큼 하면 TV를 다시 켬. 끄면 부모가 [재개]를 눌러야 켜짐 |
| 초과 개수 넘기기 | 끔 | 더 한 만큼 다음 구간에 미리 적립 |
| 앉음/일어섬 무릎 각도 | 100° / 160° | 잘 안 세지면 앉음 각도를 올리고(예: 110), 대충 해도 세지면 내리기 |

### 부모 PIN

아이들이 설정을 몰래 바꾸지 못하게 PIN을 걸 수 있어요:

```bash
python -m tvsquat --tv-ip ... --pin 1234
```

(또는 [설정]에서 "새 부모 PIN" 입력). 이후 설정 변경·일시정지·재개에는 PIN이 필요합니다.

### 휴대폰에서 확인/설정하기

`--host 0.0.0.0` 으로 실행하면 같은 와이파이의 휴대폰에서 `http://<노트북IP>:8765` 로 접속해 현황을 보고 설정을 바꿀 수 있어요.
휴대폰 화면에서는 카메라 인식이 안 되고, 카메라는 노트북의 `localhost` 화면에서만 동작합니다. 이 경우 PIN을 꼭 설정하세요.

## 동작 방식

```
[카메라] → 브라우저 (MediaPipe 포즈 인식, 무릎 각도로 스쿼트 판정)
              │  스쿼트 1개마다 POST /api/rep
              ▼
       Python 서버 (타이머·할당량 판정)
              │  미달 → KEY_POWER로 끄기 / 완료 → Wake-on-LAN으로 켜기
              ▼
         삼성 TV (samsungtvws, 포트 8001/8002)
```

- 스쿼트 판정: 무릎(엉덩이-무릎-발목) 각도가 160° 이상(서 있음) → 100° 이하(앉음) → 다시 160° 이상이 되면 1개.
- 판정은 서버가 하므로 브라우저 탭을 닫거나 카메라를 가려도 개수가 안 올라가서 결국 TV가 꺼집니다.
- 영상은 브라우저 안에서만 처리되고 어디에도 전송·저장되지 않습니다.

### 인터넷 없이 쓰기

처음 실행할 때 인식 모델(약 6MB)과 라이브러리를 인터넷(CDN)에서 받습니다. 미리 받아두려면:

```bash
python scripts/download_vendor.py
```

## 문제 해결

- **TV가 안 꺼져요**: `python -m tvsquat off --tv-ip ...` 로 테스트. 연결 허용 팝업이 다시 뜨면 허용. `tv-token.txt`를 지우고 `pair`를 다시 해보세요.
- **TV가 안 켜져요**: `--tv-mac` 지정 여부와 "모바일로 TV 켜기" 설정을 확인하세요. 일부 모델은 꺼진 지 오래되면 Wake-on-LAN에 반응하지 않을 수 있어요. 그땐 리모컨으로 켜면 됩니다.
- **2015년 이전 삼성 TV(Orsay 기반)** 는 이 방식(samsungtvws)을 지원하지 않습니다.
- **스쿼트가 안 세져요**: 발끝까지 보이게 카메라를 멀리 두고, 밝은 곳에서 해 보세요. 카메라 화면 오른쪽 세로 막대가 초록색이 될 만큼 앉아야 1개로 셉니다.
